# The correlation between serve success and location of the server

## Summary

Jim Stone reports a statistical relationship that most serving instruction ignores: where the server stands along the end line correlates with the opponent's sideout efficiency. Serving down the line produces a significant drop in opponent sideout efficiency, so the line serve is the higher-value serve on the reward side of the ledger.

Stone immediately prices the risk. The line serve travels a shorter distance and runs close to the sideline, so it is mechanically harder to land, and the coach's decision is an explicit reward-versus-risk trade rather than a pure "serve here" instruction. His second finding is the complement: serving from the middle of the court is the less lethal position, and opponent sideout percentages are higher against it.

The practical implication for a coach is that server starting position deserves the same deliberate attention as target selection. A server who always sets up in the middle of the end line has forfeited part of the serve's value before contact.

## Key claims / ideas

- Stone: there is a measurable correlation between where the server lines up on the end line and serving success, so server location is itself a tactical variable.
- Stone: serving down the line produces a significant drop in the opposing team's sideout efficiency.
- Stone: the line serve is harder to execute because it covers less distance and flirts with the sideline, making it an explicit balance of reward and risk.
- Stone: serving from the middle of the court is a less lethal location, and opponent sideout percentages are higher from there.
