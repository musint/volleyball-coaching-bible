# Developing a serving routine

## Summary

Ray Bechard (Kansas 1998 to 2024) gives four design criteria for a pre-serve routine and adds one coach-side condition. The criteria are deliberately austere: the routine must be repeatable, it should be simple in preference to complex, the toss inside it should carry minimal motion, and it must include a mental component such as a breath or a repeated phrase.

The fourth criterion is the one that separates this from a mechanics checklist. Bechard treats the routine as a container for an attentional cue, so the server has something to run in her head as well as something to run with her body. The coach-side condition is that the bench matters: positive energy, good body language, and audible encouragement from the sideline help the server execute the routine.

## Key claims / ideas

- Bechard: a serving routine must be repeatable above all else.
- Bechard: simple routines outperform complex ones.
- Bechard: the toss inside the routine should involve minimal motion, which reduces the number of variables the server has to reproduce.
- Bechard: the routine needs a mental component, for example a deep breath or a phrase repeated before every serve.
- Bechard: coach and bench body language is part of the server's environment; positive energy and encouragement from the bench help the server.
